# Hello Agent 🤖

A simple Agentic AI project built with Python.

This project is created for learning and experimenting with AI agents, LLMs, and API-based AI applications.

## 🚀 Project Overview

The purpose of this project is to understand how an AI Agent works and how it can communicate with a Large Language Model (LLM).

The project uses Python and environment variables to securely manage API keys.

```text
